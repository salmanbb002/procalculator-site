UCAS Tariff Points Calculator

Add up UCAS tariff points from A-level and BTEC grades.

What is the UCAS Tariff Points Calculator?

A UCAS tariff points calculator adds up the total UCAS Tariff points earned from A-level grades, the points-based system UK universities use to set entry requirements. It works by looking up each A-level grade against the official UCAS Tariff table (A* = 56 points, A = 48, B = 40, C = 32, D = 24, E = 16) and summing the points across all the grades you've entered. To calculate it manually, look up each of your grades on the published UCAS Tariff table and add the points together — BTECs, Scottish Highers, the International Baccalaureate and other qualifications use entirely separate tariff tables not covered by A-level points alone, so check ucas.com for the specific table matching your qualifications.

How it works

UCAS Tariff points convert qualification grades into a standardised numerical score, so universities can compare applicants holding different qualification types on a common scale. For A-levels, each grade maps to a fixed points value under the current Tariff system, and your total points are simply the sum across all your qualifications.

UK context

Not every university course uses Tariff points for entry requirements — many specify exact grades directly (e.g. "AAB") instead — but where a course does quote a points requirement, this is exactly the standardised system being referenced. Other qualification types (BTEC, Scottish Highers, the International Baccalaureate) use their own separate Tariff tables with different point values, not included in this calculator's A-level-focused table.

Tips

  • Always check the specific course's entry requirements page directly — some courses require specific grades in particular subjects regardless of your total Tariff points.
  • If you're combining A-levels with another qualification type (like a BTEC), check ucas.com's full tariff tables for that qualification's specific point values.

Frequently asked questions

Do all universities use UCAS Tariff points for entry?

No — many specify exact grades directly instead of a points total. Where a course does quote a Tariff points requirement, this calculator's table reflects the standard A-level points values.

Does this calculator cover BTEC and other qualifications?

No — this covers A-level grades only. BTECs, Scottish Highers, the International Baccalaureate and other qualification types use separate Tariff tables with different point values, available on ucas.com.

A quick note

Uses the standard UCAS Tariff points table for A-levels only. Check ucas.com for BTEC, IB and other qualification tariff tables.
